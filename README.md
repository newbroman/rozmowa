# Rozmowa 🇵🇱

Free spoken-conversation practice in Polish. Talk to it; it replies in a native Polish voice and corrects your mistakes (cases, aspect, agreement, Pan/Pani) as you go.

- Speech recognition: browser (Chrome / Android), pl-PL
- Conversation + corrections: Google Gemini API (free tier, bring your own key from https://aistudio.google.com/apikey — stored only on your device)
- Voice: your device's Polish text-to-speech voice (Android: Settings → Accessibility → Text-to-speech → Google → install Polski)
